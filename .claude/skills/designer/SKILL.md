# Designer (모바일 우선 디자인 시스템)

콘셉트: **아이보리 종이 노트 위의 먹(墨)과 와인색 포인트**. 공부 노트처럼 차분하고, 한자가 주인공인 화면.
AI 서비스 특유의 보라·인디고 그라데이션은 쓰지 않는다.

## 토큰 — `globals.css` CSS 변수 + Tailwind 테마에 등록
| 토큰 | 값 | 용도 |
|---|---|---|
| `--paper` | `#FAF7F0` | 앱 배경 |
| `--surface` | `#FFFFFF` | 카드, 바텀시트 |
| `--ink` | `#1F1B16` | 본문, 한자 획 |
| `--muted` | `#6B645A` | 보조 텍스트, 후리가나 |
| `--line` | `#E7E0D4` | 구분선, 획순 외곽선·가이드선 |
| `--accent` | 와인색 계열 — 값은 `docs/design.md`에서 확정 (순빨강 `#D2452B`류 금지) | 주요 버튼, 현재 획, 선택 상태 |
| `--accent-soft` | accent의 아주 연한 톤 — `docs/design.md` | 선택된 칩 배경 |
| `--ok` | `#3E7B57` | 정답, 저장 완료 |

대비: muted/paper ≈ 5.4:1, 흰 글자/accent ≥ 4.5:1 (AA 통과). 이보다 옅은 텍스트 색은 만들지 않는다.
- 기준 문서는 `docs/design.md` (grill-me 11-06 결정): T2 셸 단계에서 레퍼런스 조사(5분 상한)로 값을 확정하고 그 값으로 위 표를 갱신한다. 배경은 연한 아이보리, 텍스트·획에 순검정 `#000000` 금지(`--ink` 같은 먹색), 포인트는 와인색 계열. 폴리싱은 셸 단계 10분 상한.

## 타이포 (`next/font/google`)
- UI 한국어: Noto Sans KR · 일본어 본문: Noto Sans JP · 큰 한자 표시: **Klee One** (교과서체 느낌)
- 본문 16px 이상. **입력창은 반드시 16px 이상** (iOS 포커스 확대 방지).
- 일본어 본문 line-height 1.8, `<rt>`는 0.55em · `--muted`.
- 큰 한자 헤더 48~64px Klee One.

## 레이아웃
- 기준 375×812, 콘텐츠 `max-w-md mx-auto`. 가로 스크롤 금지.
- 높이는 `100dvh` (`100vh` 금지). `viewport-fit=cover`, 하단 고정 요소에 `padding-bottom: env(safe-area-inset-bottom)`.
- 하단 탭 2개: **한자 / 학습** (아이콘 + 라벨, 56px + safe area). 학습 탭 = (S3가 되면) 내 한자장 섹션 + 문법·독해·청해 준비중 카드 3개.
- 홈(한자) 화면 `/`: 검색 바 → 입력 방식 버튼(입력 · 손글씨, 사진은 S2 때) → 결과 칩 → (S4) 최근 검색. 질문 채팅 화면은 오늘 만들지 않는다. 키보드가 올라와도 입력창이 보여야 한다.
- 한자 상세는 페이지 이동 대신 **바텀시트** (~75dvh, 드래그 핸들, 배경 탭·닫기 버튼으로 닫힘).
- 간격 4px 단위(4/8/12/16/24/32). 카드 radius 16, 칩 radius full. 그림자는 아주 옅게 1단계만.

## 모든 화면의 3가지 상태 (필수)
- **로딩**: 스트리밍 중 점 3개 / 스켈레톤. 누른 버튼은 비활성 + 스피너.
- **빈 상태**: 예시 한자 칩 3개 (예: `履歴書` · `面接` · `職`) — 탭하면 바로 검색.
- **에러**: 원인 한 줄 + [다시 시도] 버튼.

## "준비중" 패턴 (확장 예정 기능)
- 아직 만들지 않은 기능도 화면에는 둔다. 단 **누르기 전에 준비중임이 보여야 한다**: 메뉴·카드에 작은 `준비중` 배지 (`--muted` 테두리 칩).
- 탭하면 모달(바텀시트): 아이콘 + 제목 "서비스 준비중입니다" + 이 기능이 무엇을 해 줄지 한 줄(`features.ts`의 pitch) + [확인] 버튼. 제목만 덩그러니 쓰지 않는다.
- 공통 컴포넌트 하나(`ComingSoonSheet`)로 만들고, 기능 목록은 `src/lib/features.ts`의 `{ id, label, status: 'live' | 'soon', pitch }` 배열로 관리한다. 기능이 완성되면 status만 바꾼다.
- 준비중 항목은 **최대 3개**. 많으면 미완성 앱처럼 보인다. 데모 핵심 동선(첫 화면 → 검색 → 획순) 위에는 두지 않는다.

## 접근성
- 터치 타깃 44×44 이상, 아이콘 버튼에 `aria-label`, `focus-visible` 링은 `--accent`.
- `prefers-reduced-motion`이면 자동 애니메이션 끄고 버튼으로 재생.

## 하지 말 것
보라/인디고 기본색, 의미 없는 그라데이션, 이모지 장식, 12px 이하 본문, 회색 위 옅은 회색 글자, 화면마다 다른 버튼 모양.
