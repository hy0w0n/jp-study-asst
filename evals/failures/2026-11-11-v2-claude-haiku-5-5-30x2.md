결정적 검사 실패(참고 검사 포함) · 판정 3점 이하 · 오류가 있는 카드 4장

## 社 (run 2)
- 판정 example 3점: '会社に入社して'는 겹말이고, 입사해서 사원이 됐다는 내용도 동어반복이라 부자연스럽다.

```
**음독** シャ · **훈독** やしろ
**뜻**: 회사, 사회, 신사
**한국 한자와 차이**: 같음
**자주 쓰는 단어**:
- {会社|かいしゃ} — 회사
- {社員|しゃいん} — 사원
**예문**: {会社|かいしゃ}に{入社|にゅうしゃ}して、{社員|しゃいん}になりました。 → 회사에 입사해서 사원이 되었습니다.
```

## 仕 (run 2)
- 판정 example 2점: 「仕事を仕方から学ぶ」는 조사 연결이 어색한 부자연스러운 문장이다. 「仕事の仕方から学ぶ」나 「仕事の仕方を学ぶ」가 자연스럽다.
- 판정 translation 3점: '일하는 방법부터 배운다'는 의도한 뜻으로 보이지만, 원문의 「仕事を…仕方から」 구조와 정확히 대응하지 않는다.

```
**음독** シ、ジ · **훈독** つかえる
**뜻**: 섬기다, 일하다
**한국 한자와 차이**: 같음
**자주 쓰는 단어**:
- {仕事|しごと} — 일, 직업
- {仕方|しかた} — 방법, 수단
**예문**: {仕事|しごと}を{仕方|しかた}から{学|まな}ぶ。 → 일하는 방법부터 배운다.
```

## 経 (run 1)
- 판정 meaning 3점: '지나다'는 pass thru와 맞지만 '다스리다, 경영하다'는 사전 뜻에 없고, sutra(경전)·longitude(경도)·warp(날실) 같은 핵심 뜻이 빠졌다.

```
**음독** ケイ、キョウ、キン · **훈독** へる、たつ、たていと、はかる、のり
**뜻**: 다스리다, 경영하다, 지나다
**한국 한자와 차이**: 다름 — 한국 經
**자주 쓰는 단어**:
- {経営|けいえい} — 경영
- {経験|けいけん} — 경험
**예문**: {会社|かいしゃ}の{経営|けいえい}を{学|まな}ぶ。 → 회사 경영을 배운다.
```

## 経 (run 2)
- 판정 meaning 2점: 사전 뜻의 핵심인 '지나다(pass thru)'와 '경전(sutra)', 경도·날실이 빠져 있다. 대신 사전에 없는 '다스리다, 경영'만 제시되어 기준과 어긋난다.

```
**음독** ケイ、キョウ、キン · **훈독** へる、たつ、たていと、はかる、のり
**뜻**: 다스리다, 경영
**한국 한자와 차이**: 다름 — 한국 經
**자주 쓰는 단어**:
- {経営|けいえい} — 경영
- {経済|けいざい} — 경제
**예문**: {会社|かいしゃ}の{経営|けいえい}を{学|まな}ぶ。 → 회사 경영을 배운다.
```
