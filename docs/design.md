# SENSE 디자인 기준 (T2에서 확정)

콘셉트: **한자 연습장(漢字練習帳) 위의 먹과 蘇芳(すおう)색**. 한자는 언제나 십자 가이드선이 있는 연습 칸 안에 앉는다 — 이 칸이 SENSE의 유일한 시각 장치다. 나머지는 조용하게.

## 레퍼런스 (5분 조사)
- 일본 초등 한자 연습장 · 원고지: 정사각 칸 + 점선 십자 가이드 → 한자 칩·카드 아이콘·탭 아이콘에 그대로 사용
- 일본 전통색 蘇芳(すおう, 붉은 와인색) → accent. 순빨강·주황 계열과 구분되는 깊은 톤
- 교과서체(Klee One) → 큰 한자는 획 모양이 정확한 교과서체로, 획순 학습과 어울림

## 타입
- UI 한국어: Noto Sans KR (`font-sans`) · 일본어 본문: Noto Sans JP (`font-jp`, line-height 1.8) · 큰 한자: Klee One (`font-brush`)
- 크기: 제목 26/700 · 본문 16 · 보조 14(muted) · 입력창 17 · 큰 한자 48~64
- 전부 대문자 라벨, 강조 한 단어만 색 바꾸기 금지

## 레이아웃
- 콘텐츠 `max-w-md`, 좌우 20px, 왼쪽 정렬. 높이 `100dvh`
- 하단 탭 2개(한자 `/` · 학습 `/learn`): 56px + safe-area, 활성은 accent
- 연습 칸(`KanjiCell`): 정사각, `--line` 테두리, 점선 십자 가이드, 한자는 Klee One
- radius: 카드·시트 16 · 입력창 14 · 칩 full / 연습 칸 6. 그림자는 시트에만 1단계
